## Android: INSTALL_FAILED_USER_RESTRICTED

إذا ظهر عند التثبيت على الجهاز (مثل Realme/Xiaomi):
`INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`

- فعّل **التثبيت عبر USB** من إعدادات المطوّر (Developer options).
- على بعض الأجهزة: إيقاف **MIUI Optimization** ثم إعادة التشغيل.
- أو انقل ملف الـ APK إلى الجهاز وثبّته يدوياً من مدير الملفات بعد السماح بـ "مصادر غير معروفة".
